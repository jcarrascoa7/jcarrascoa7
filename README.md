## 🤖 How I work with AI

Coding agents are my day-to-day way of building software. I don't use them as autocomplete: I treat them as a team I direct, and I own the design, the review and the verification.

**🧭 Plan first, then delegate.** Every project starts with a written roadmap and one feature per PR. The agent implements; I review every diff and decide what gets merged.

**🧩 Give agents real tools.** I write my own **MCP servers** and skills so agents can work with the systems I use (spreadsheets, cloud storage, schedulers, GPU pods) instead of me copy-pasting context.

**🔀 Run work in parallel.** I split work across several agent sessions, each in its own git worktree, and merge the results back once they're verified.

**✅ Trust, but verify.** Agents must prove a change works (tests, a real run, a screenshot) before I accept it. Security audits and robustness passes are part of the workflow, not an afterthought.

**💸 Treat tokens and GPUs as a budget.** I keep context lean with token-filtering CLIs, and every cloud GPU job carries a watchdog that shuts it down automatically when it's done.

**🧠 Make agents remember.** Persistent memory and project notes let each new session pick up decisions, gotchas and next steps where the last one left off.

## 🔭 What that looks like in practice

- 📲 **Automation from end to end:** bank notifications → webhooks → a database → a dashboard, with no manual data entry.
- 🎙️ **LLM-powered products:** speech-to-text and LLM pipelines served from serverless containers.
- 👁️ **Computer vision on real data:** OCR and vision pipelines that turn hours of video into structured, analyzable events.
- 🧪 **Measuring, not guessing:** I benchmark VLMs against embedding classifiers (AUC, agreement with human labels) before trusting a model with a decision.
- ☁️ **On-demand GPU infrastructure:** generative image and video pipelines on rented GPUs that launch, run and tear themselves down.
